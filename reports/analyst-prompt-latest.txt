## 输出格式

对每只股票输出结构化分析后，最后给出综合评级JSON：

```json
{
  "analysis_date": "2026-03-27",
  "recommendations": [
    {
      "code": "000xxx",
      "name": "股票名",
      "rating": "buy/hold/avoid",
      "confidence": 0.0-1.0,
      "target_price": 目标价,
      "stop_loss": 止损价,
      "entry_price": 建议介入价(不是当前价,而是回调到哪里可以买),
      "reasons": ["Bull理由1", "Bull理由2"],
      "risks": ["Bear理由1", "Bear理由2"],
      "technical_summary": "技术面一句话总结",
      "hold_days": 建议持有天数,
      "position_pct": 建议仓位比例(1-10表示10%到100%)
    }
  ],
  "market_view": "整体市场判断",
  "top_picks": ["最推荐的1-2只代码"]
}
```

**评级标准：**
- buy: Bull明显强于Bear + 技术面支持 + confidence>=0.65
- hold: 有机会但风险也大，等更好入场点
- avoid: Bear明显强于Bull 或 技术面超买 或 基本面有硬伤

**重要：**
- entry_price ≠ 当前价。短线最佳介入是回调到支撑位，不是追涨
- stop_loss设在关键支撑下方2-3%
- 5日涨幅>15%的默认给hold或avoid，除非有极强催化剂
- PE为负（亏损企业）扣分
- 请在JSON之前先输出每只股票的分析过程
